# Tradingview指标

本仓库收录 TradingView 指标。每个指标有独立文件夹，内含 Pine Script 源码和中文说明。

## 指标总览

| 指标 | 简介 |
| --- | --- |
| [YeĦ.btc](Ye%C4%A6.btc/) | 图表水印，支持两行自定义文字，显示品种、周期和日期时间，并可开启报价币换算。 |
| [关键价位套件](%E5%85%B3%E9%94%AE%E4%BB%B7%E4%BD%8D%E5%A5%97%E4%BB%B6/) | 多周期关键价位、VWAP、均线、交易时段、成交量分布和星期价位。 |
| [VWAP D/W/M/Q/Y](VWAP%20D-W-M-Q-Y/) | 多周期 VWAP，默认显示周线及本期和上期标准差区间。 |
| [Rolling VWAP](Rolling%20VWAP/) | 四组滚动 VWAP，价格标签跟随线色，7 日上下轨可一起开关。 |

仓库中的指标默认在状态行隐藏输入值。
