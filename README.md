# Tradingview指标

本仓库收录使用 Pine Script® 编写的 TradingView 指标，源码统一存放在「指标」文件夹。

## 指标列表

| 指标 | 说明 | 源码 |
| --- | --- | --- |
| YeĦ.btc | 图表水印，显示自定义文字、品种、周期和日期时间。 | [查看源码](%E6%8C%87%E6%A0%87/YeH-btc.pine) |

## YeĦ.btc

- 右上角默认只显示两行文字。第一行是白色的 `YeĦ.btc⚔️`，第二行是绿色的 `Always long🧲💹`。
- 右下角默认显示品种、周期和 GMT+8 日期时间。星期默认关闭，可在指标设置中开启。
- 两行文字和颜色可以分别修改，字号共用。文字水印与品种日期可分别调整位置。

## 使用方法

打开对应的 `.pine` 源码文件，复制全部内容。在 TradingView 图表中打开 Pine 编辑器，新建指标并粘贴源码，然后点击「添加到图表」。
