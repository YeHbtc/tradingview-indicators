# TPO

基于 YeH_btc 提供的源码汉化，保留按图表 K 线统计的连续轮廓，默认周级别。

## 默认外观

| 项目 | 默认设置 |
| --- | --- |
| 轮廓周期 | 周线，可选日线、月线 |
| 分层数 / 宽度 / 价值区域 | 100 / 30% / 70% |
| 价值区内轮廓 | 灰色 `#808080`，不透明度 50% |
| 价值区外轮廓 | 灰色 `#808080`，不透明度 20% |
| POC | 绿色 `#39D600`，实线，粗细 2 |
| VAH / VAL | 红色 `#FF0000`，虚线 |
| 单印区间 | 紫色 `#8040FF`，不透明度 40%，开启延长 |
| IB | 开启，浅橙色 `#FFCC80`；延长线不透明度 60%，默认不延长 |

价值区高亮只沿轮廓形状绘制，不再用矩形覆盖整段 K 线。单印区间在轮廓中直接使用紫色，避免被灰色轮廓覆盖；延长部分使用同样颜色。

设置按图形集中排列：填色、POC、VAH/VAL、单印区间与 IB 各自的开关和颜色放在同一行，相关粗细、线型紧邻。IB 使用浅橙色区分灰色轮廓，计算逻辑不变。

## IB 计算

按所选轮廓开始后的前两个 30 分钟时间块计算，即首个小时的最高价和最低价，之后固定，直到下一轮廓重置。默认周轮廓因此只统计每周开始的首小时，不再累计每天东京 09:00–10:00。

30 分钟及以下图表使用首小时内图表 K 线；更大图表通过 30 分钟数据计算，避免将整根大周期 K 线计入。周期边界使用品种交易所的周期划分。若加载历史缺少周期开头，IB 可能缺失或不完整。

## 使用与限制

复制同目录「指标源码.pine」到 TradingView Pine 编辑器，添加至图表。旧实例可能保留旧颜色，需重置设置或重新添加。

全部输入使用 `display.none` 隐藏状态行输入值；平台的复选框勾选状态不能由源码强制设置。

轮廓、POC、价值区和单印识别保留原源码按图表 K 线覆盖次数的算法，所以不同图表周期的结果会不同。单印延长至本轮廓末端，不含首次触及后停止、弱势高低点或字母时间块功能。没有新增成交量分布。

分段着色会使用更多绘图对象；最多保留 90 个轮廓色段，超限删除最早色段，历史最早轮廓可能不完整。没有将其改成官方内置 TPO 算法。
