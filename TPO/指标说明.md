# TPO

基于 YeH_btc 提供的 Pine Script v6 源码汉化，保留原来的计算算法与连续轮廓形状，指标名及简称均为 **TPO**。本次只调整默认周期与配色。

## 默认设置

| 项目 | 默认值 |
| --- | --- |
| 轮廓周期 | 周线，可选日线、月线 |
| 价格分层数 | 100 |
| 轮廓宽度 | 30% |
| 价值区域占比 | 70% |
| 轮廓 | 灰色 `#808080`，不透明度 70% |
| POC | 亮绿色 `#39D600`，不透明度 100%，实线、粗细 2 |
| VAH / VAL | 红色 `#FF0000`，不透明度 100%，虚线 |
| 价值区域填充 | 灰色 `#808080`，不透明度 15% |
| 单印区间 | 紫色 `#8040FF`，不透明度 15%，开启延长 |
| IB | 灰色，开启；延长线关闭 |

设置为中文。所有输入使用 `display.none`，默认不向状态行输出输入值。TradingView 的“状态行中的输入”复选框由平台管理，源码不能强制修改该复选框；本次测试图表中已取消勾选。

## 使用与算法

复制同目录「指标源码.pine」到 TradingView 新建 Pine 指标，添加到图表。已有实例可能保存旧参数，需重置设置或重新添加才能使用新默认值。

沿用原源码按图表 K 线高低范围统计价格层被覆盖次数的算法，因此结果会随图表周期变化，并非独立 30 分钟时间块算法，也不是成交量分布。

IB 沿用东京时间 09:00–10:00 的统计逻辑。原源码没有弱势高低点、字母时间块、触及后自动停止延伸等功能，本次未新增。

## 验证记录

2026-11-08：本次配色及默认周轮廓版本通过 TradingView Pine v6 编译，在 Coinbase BTC/USD 的 1 小时图运行，核对周轮廓、灰色填充、绿色 POC、红色价值区域边界和中文参数，未见编译或运行错误。设置窗口确认轮廓周期为「1 周」。上传源码与测试版本校验一致。

本次没有完成原源码在 1 分钟图上的性能验证，也未穷举所有品种及参数组合。
