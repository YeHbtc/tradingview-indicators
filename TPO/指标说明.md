# TPO

基于 YeH_btc 提供的源码汉化，保留按图表 K 线统计的连续轮廓，默认周级别。

## 默认外观

| 项目 | 默认设置 |
| --- | --- |
| 轮廓周期 | 周线，可选日线、月线 |
| 分层数 / 宽度 / 价值区域 | 100 / 30% / 70% |
| 价值区内轮廓 | 灰色 `#808080`，不透明度 50% |
| 价值区外轮廓 | 灰色 `#808080`，不透明度 20% |
| POC | 绿色 `#39D600`，实线，粗细 2 |
| VAH / VAL | 红色 `#FF0000`，虚线 |
| Single Prints | 紫色 `#8040FF`，不透明度 40%，开启延长 |
| IB | 开启，浅橙色 `#FFCC80`；延长线不透明度 60%，默认不延长 |

价值区高亮只沿轮廓形状绘制，不再用矩形覆盖整段 K 线。Single Prints在轮廓中直接使用紫色，避免被灰色轮廓覆盖；延长部分使用同样颜色。

设置按图形集中排列，每行开关在最左侧：

- POC：开关、色块、线型、粗细。
- VAH / VAL：开关、色块、线型。
- IB：开关、色块、粗细。
- IB 延长线：开关、色块、线型。
- Single Prints：开关、延长开关、色块。
- 价值区高亮：开关、区内色块、区外色块。

删除重复的“颜色”和“粗细”文字，保留粗细数值调节框。正常设置窗口宽度下以上各组为单行；窄窗口可能自动换行。IB 使用浅橙色，计算逻辑及默认参数保持不变。

## IB 计算

按所选轮廓开始后的前两个 30 分钟时间块计算，即首个小时的最高价和最低价，之后固定，直到下一轮廓重置。默认周轮廓因此只统计每周开始的首小时，不再累计每天东京 09:00–10:00。

30 分钟及以下图表使用首小时内图表 K 线；更大图表通过 30 分钟数据计算，避免将整根大周期 K 线计入。周期边界使用品种交易所的周期划分。若加载历史缺少周期开头，IB 可能缺失或不完整。

## 使用与限制

复制同目录「指标源码.pine」到 TradingView Pine 编辑器，添加至图表。旧实例可能保留旧颜色，需重置设置或重新添加。

全部输入使用 `display.none` 隐藏状态行输入值；平台的复选框勾选状态不能由源码强制设置。

轮廓、POC、价值区和单印识别保留原源码按图表 K 线覆盖次数的算法，所以不同图表周期的结果会不同。Single Prints 仅按当前图表 K 线识别；例如 1 小时图使用 1 小时 K 线。切换图表周期时重新计算，不叠加其他周期结果。

开启“延长”时，轮廓结束确认的 Single Prints 跨周期逐根更新右边界，最多延伸到当前 K 线的时间位置，不进入右侧未来空白区；下一轮廓第一根及后续 K 线的最高/最低范围与区间相交（含边界和影线）时，整个区间停止在该根 K 线的起始时间。停止后保留历史矩形，不再延长。跳空越过而无高低范围相交不算触碰。当前未结束轮廓的区间仍为动态预览，边界可变化或消失，待轮廓结束后才固定并进入触碰跟踪。

关闭“延长”则只保留轮廓内着色。不含弱势高低点或字母时间块功能。没有新增成交量分布。

分段着色会使用更多绘图对象；最多保留 90 个轮廓色段，超限删除最早色段，历史最早轮廓可能不完整。已确认 Single Prints 矩形最多保留 240 个，为当前轮廓预览预留绘图容量；超限删除最早矩形并停止跟踪，包含可能尚未触碰的旧区间。没有将其改成官方内置 TPO 算法。

## 价格轴缩放

若远处 Single Prints 压缩 K 线，右键价格轴启用“仅缩放价格图表”，并保持自动缩放。此项是图表布局设置，不是 Pine 输入，会排除所有指标绘图对自动缩放范围的影响。2026-11-09 已在当前布局开启。

## 图层顺序

源码设置 `behind_chart = false`，默认在 K 线上层绘制。修改此声明后应重新添加指标；对象树手动调整的顺序优先，源码不能锁定或覆盖用户手动置底。参见 [TradingView 绘图层说明](https://www.tradingview.com/pine-script-docs/visuals/overview/)。
