# YeĦ.btc

图表水印指标，使用 Pine Script® v6 编写。

- 右上角默认只显示两行文字。第一行是白色的 `YeĦ.btc⚔️`，第二行是绿色的 `Always long🧲💹`。
- 右下角默认显示品种、周期和 GMT+8 日期时间。星期默认开启，可在指标设置中关闭。
- 两行文字和颜色可以分别修改，字号共用。文字水印与品种日期可分别调整位置。

- 两组水印在上下各留一行，左右各留出少量空间。
- 「显示换算」默认关闭。开启后，文字水印下方会显示用指定报价币金额按当前图表价格可换算的品种数量。金额默认 100，可修改。比如价格为 50 USDT 时，100 USDT 可换算为 2 个单位。换算按价格估算，未计入费用、最小下单量或合约乘数。
- 输入值默认隐藏于状态行，可在指标设置中调整。

## 使用方法

打开 [指标源码](%E6%8C%87%E6%A0%87%E6%BA%90%E7%A0%81.pine)，复制全部内容。在 TradingView 图表中打开 Pine 编辑器，新建指标并粘贴源码，然后点击「添加到图表」。
