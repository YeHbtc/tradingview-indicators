# 关键价位套件

Pine Script® v6 图表指标，根据公开功能说明和配置截图独立实现。

[原版 Key Levels Suite - By Leviathan](https://cn.tradingview.com/script/y79XVnBl-Key-Levels-Suite-By-Leviathan/)

## 默认显示

| 标签 | 价位 |
| --- | --- |
| dO | 本日开盘 |
| wO | 本周开盘 |
| pwO | 上周开盘 |
| pwH | 上周最高 |
| pwL | 上周最低 |

六组分类的总开关默认开启。除以上五条高周期线外，其他单项默认关闭。标签默认显示名称、价格和相对现价的百分比距离，线型为一像素实线，左右偏移默认分别为 0 和 35 根 K 线。默认仅合并价格相同的线位。

## 设置

高周期、VWAP、交易时段和成交量分布的历史行可选 `p`（上期）或 `pp`（上上期）。默认选 `p`，切换只影响对应历史行。均线和 VWAP 的选项分别显示 `MA / EMA` 和 `VWAP / SD`。

- **高周期价位**。四组可选周期，显示本期或上期开盘、最高、最低和高低中点。上期值取已收盘的高周期 K 线。本期高低点随图表 K 线更新。
- **成交量加权均价**。三组周期，支持本期和上期 VWAP 及上下一个标准差。
- **移动平均线**。三组默认长度为 50、100、200，分别支持简单和指数均线。
- **交易时段价位**。固定为东京 09:00–15:00、伦敦 08:00–17:00、纽约 09:30–16:00。设置按城市显示，不再提供时间或时区输入。伦敦和纽约按当地时区自动切换夏令时。纽约对应北京时间夏令时 21:30–次日 04:00，标准时 22:30–次日 05:00。时段边界的精度取决于图表周期。
- **成交量分布**。三组可选周期，支持本期与上期 POC、VAH 和 VAL。默认 50 档、70% 价值区。将图表 K 线的成交量按典型价格归入各档，再从成交量最高档向外扩展。结果随图表周期、历史长度和档数变化，可能与原版不同。每周期最多使用最近 6,000 根图表 K 线，开启优化后为 1,500 根。
- **星期价位**。三组可选星期，默认星期一、星期二和星期三。开启单项后显示该星期最近一个交易日的价位。
- **外观和标签**。可调整线型、偏移、颜色、合并容差、字体和标签缩写。输入值默认隐藏于状态行。TradingView 的「样式 → 状态行中的输入」复选框由平台控制，可在界面取消勾选。

## 安装

复制同目录的 `指标源码.pine`，在 TradingView 的 Pine 编辑器中新建指标、粘贴并点击「添加到图表」。
